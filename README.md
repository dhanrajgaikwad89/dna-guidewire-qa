# DnA — by Dhanraj & Apeksha

A Guidewire automation QA learning website with 14 topics, 429 lessons and 465 interview questions and answers.

## Learning sections

- ClaimCenter, BillingCenter and PolicyCenter — 33 lessons each.
- Java with Selenium, Playwright with TypeScript, TestNG, API testing, manual testing, database and ETL testing, Java coding, Git and GitLab, CI/CD, HR interviews and salary negotiation — 30 lessons each.

Search lessons and interview questions, study in focus mode, adjust text size, listen with read aloud, save lessons, track progress and keep a personal notebook.

## Publishing

GitHub Pages serves the website from the root of the `main` branch. In **Settings → Pages**, choose **Deploy from a branch**, `main`, and `/ (root)`. Updates pushed to `main` publish automatically.

The site uses relative asset links and hash-based routes, so it supports GitHub Pages project URLs. It is plain HTML, CSS and JavaScript with no build dependencies. Open `index.html` to preview locally, or use a static HTTP server.

## Editing

- `content.js` defines topics and introductory lessons.
- `guidewire.js` contains additional Guidewire lessons.
- `additional-concepts.js` contains expanded lessons for the other topics.
- `questions.js` contains 36 additional interview questions.
- `app.js` controls navigation and reader interactions.
- `styles.css` controls appearance.

Preserve lesson IDs to retain saved progress and links.

## Study data

Notes, bookmarks and progress are stored in each visitor's browser. They are not uploaded to GitHub. Use the notebook's JSON export/import to move them between browsers or website addresses. Read aloud uses the browser's speech synthesis and available device voices.

Guidewire workflows are general study examples; configuration and behavior can vary by product version and implementation. Applicable lessons include source references. Code examples identify setup assumptions. Handwritten documents can be incorporated in later updates.
